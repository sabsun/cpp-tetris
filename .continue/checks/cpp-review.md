---

name: C++ Review
description: Detect crashes, memory issues and security bugs
------------------------------------------------------------

Review the code changes.

Fail if you find:

* null pointer dereference
* use-after-free
* double free
* memory leak
* resource leak
* buffer overflow
* security vulnerability
* race condition

Ignore:

* formatting
* comments
* naming

Return:

PASS

or

FAIL with explanation.
